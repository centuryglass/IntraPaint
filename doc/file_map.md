# File map

One line for every source file, generated by `python scripts/file_map.py` from each module's docstring summary line.
Edit a module's docstring rather than this file, except for files with no docstring (the config definitions, shell
scripts without a header comment and `IntraPaint.spec`), whose descriptions this file holds. The script's docstring
describes the summary format, and it also writes a browsable `doc/file_map.html` with more detail.

## Project root

Entry points and build configuration.

- `IntraPaint.py`: Runs the main IntraPaint inpainting UI.
- `IntraPaint.spec`: PyInstaller spec for the Linux and Windows bundles, run by `scripts/build.sh`.
- `IntraPaint_server.py`: Starts the GLID-3-XL image inpainting server.
- `setup.py`: Builds the Cython `image_fill` extension in place: `python setup.py build_ext --inplace`.

## `resources/config`

Config option definitions, the source of truth for every option (AGENTS.md, "Config system").

- `resources/config/a1111_setting_definitions.json`: Definitions for `A1111Config`, the Stable Diffusion WebUI settings.
- `resources/config/application_config_definitions.json`: Definitions for `AppConfig`, the application settings.
- `resources/config/cache_value_definitions.json`: Definitions for `Cache`, persisted state and values.
- `resources/config/key_config_definitions.json`: Definitions for `KeyConfig`, the keybindings.

## `scripts`

Developer tools: builds, CI checks, code generation and UI captures. None of them ship with the app.

- `scripts/benchmark_brush.py`: Benchmark for the smudge, filter, draw, eraser and MyPaint brushes: times long, fast
  strokes on a large layer.
- `scripts/build.sh`: Builds the pre-packaged IntraPaint distribution file for the current platform.
- `scripts/build_libmypaint.sh`: Builds the libmypaint that IntraPaint bundles in lib/<platform tag>/, for Linux and
  macOS on the machine it runs on.
- `scripts/build_translations.py`: Builds IntraPaint's translation catalog and translation files, and checks them in CI.
- `scripts/capture_ui.py`: Saves screenshots of the style gallery, the main window and every panel, for checking layouts
  by eye.
- `scripts/check_libmypaint.py`: Checks that a lib/<platform tag>/ directory holds a loadable libmypaint with the pinned
  version's brush settings.
- `scripts/clean.sh`: Remove all build files.
- `scripts/crosshair_builder.py`: Interactive builder for `src/ui/brush_crosshair.py` crosshair patterns.
- `scripts/dynamic_import_typing.py`: Instantiate an object, read its dynamic attributes, and add appropriate type hints
  in the class definition.
- `scripts/file_map.py`: Generates `doc/file_map.md`, a one-line description of every source file, from module and
  package docstrings.
- `scripts/generate_config_keys.py`: Generates `src/config/generated_keys.py`, the config key constants, from the
  definition files in `resources/config/`.
- `scripts/issues.py`: Compile this repository's GitHub issues into a local cache an agent can read with ordinary file
  tools.
- `scripts/markdown_lint.py`: CI markdown gate: lint the repository's Markdown files with PyMarkdown, using the rules in
  .pymarkdown.yaml.
- `scripts/preview_loading_widget.py`: Opens a window that previews the loading indicator with any of its designs.
- `scripts/profile.sh`: Run with profiling, then open profile for visualization.
- `scripts/pylint.sh`: Run pylint to identify code style issues.
- `scripts/pylint_check.py`: CI lint gate: fail when pylint reports more messages than scripts/pylint_baseline.json
  allows.
- `scripts/render_loading_assets.py`: Renders the starting assets for the asset-backed loading designs, to use as they
  are or as restyle templates.
- `scripts/smoke_test_bundle.py`: Launch test for a packaged IntraPaint build: fail unless the bundle starts and reaches
  the editing state.
- `scripts/timelapse.sh`: Record timelapse videos with ffmpeg, running IntraPaint with animations turned off to suppress
  excess frame updates.

## `src`

IntraPaint's application source: config, controllers, the image model, editing tools, UI and utilities.

- `src/hotkey_filter.py`: Passes ImageViewer input events to an active editing tool.
- `src/undo_stack.py`: Global stack for tracking undo/redo state, as a thin wrapper over a QUndoStack.

## `src/config`

Typed, JSON-backed config singletons: app settings, cached values, keybindings and WebUI settings.

- `src/config/a1111_config.py`: Provides access to configurable options for the Automatic1111 or Forge Stable Diffusion
  WebUI.
- `src/config/application_config.py`: Provides access to the user-editable application config.
- `src/config/cache.py`: Use the Config module's data sharing capabilities to cache temporary values.
- `src/config/config.py`: A shared resource to set inpainting configuration and to provide default values.
- `src/config/config_entry.py`: Represents configurable typed values loaded from JSON definitions.
- `src/config/config_from_key.py`: Get the config object that contains a particular key.
- `src/config/definition_tr_contexts.py`: The translation context of each config definition file's labels, descriptions,
  categories and options.
- `src/config/generated_keys.py`: Config key constants, generated from `resources/config/*_definitions.json`.
- `src/config/key_config.py`: Provides access to the user-editable application keybinding config.

## `src/controller`

Coordinators that connect the image model, tools, UI, config and generators around `AppController`.

- `src/controller/app_controller.py`: AppController coordinates almost all IntraPaint application behavior.
- `src/controller/autosave_controller.py`: Keeps a crash recovery copy of the open document, and offers to restore one
  left by a session that crashed.
- `src/controller/color_controller.py`: Foreground/background color pair operations, and the recent and saved color
  lists.
- `src/controller/generation_area_controller.py`: Keeps the generation resolution, recent frame sizes and generation
  area position in step with the image.
- `src/controller/image_io.py`: ImageIO owns opening and saving image files for the application.
- `src/controller/spacenav_manager.py`: Enables moving the edited image section using a spacemouse.
- `src/controller/tool_controller.py`: Manages available tools and handles tool input events.

- `src/controller/image_generation/image_generator.py`: Interface for providing image generation capabilities.
- `src/controller/image_generation/mask_blur.py`: Geometry of the inpainting mask blur band, shared by everything that

  what the result changed.
- `src/controller/image_generation/sd_comfyui_generator.py`: Generates images through Stable Diffusion and ComfyUI,
  using the `sd_backend_client` library's ComfyUI client.

## `src/controller/image_generation/sd_adapters`

Converts between IntraPaint's Qt images and saved settings and the `sd_backend_client` library's models.

- `src/controller/image_generation/sd_adapters/controlnet_adapter.py`: Converts between saved ControlNet settings and
  the library's `ControlNetUnit`.
- `src/controller/image_generation/sd_adapters/credentials_adapter.py`: Supplies the `credentials_provider` the
  library's `A1111Webservice` calls when the server answers 401.
- `src/controller/image_generation/sd_adapters/image_adapter.py`: Converts images between IntraPaint's QImages and the
  PIL images `sd_backend_client` takes and returns.
- `src/controller/image_generation/sd_adapters/params_adapter.py`: Builds `sd_backend_client` request parameters from
  IntraPaint's cached generation settings.
- `src/controller/image_generation/sd_adapters/progress_adapter.py`: Converts the library's `GenerationProgress`
  snapshots into IntraPaint's generation status updates.
- `src/controller/image_generation/sd_adapters/soft_inpainting_adapter.py`: Reads and writes the saved soft inpainting
  settings, whose controls come from the connected backend.

## `src/image`

The edited image model: layers, brushes, filters, MyPaint bindings, composite modes and file formats.

- `src/image/animation.py`: Maps animation frames to layers: one top-level layer per frame, with the first frame at the
  bottom of the stack.
- `src/image/composite_mode.py`: Layer composition modes: conversion between Qt and OpenRaster modes, and the modes
  QPainter lacks.
- `src/image/image_metadata.py`: The metadata an image file carries, kept per source so a save writes back what a load
  read.
- `src/image/metadata_cache_fields.py`: The mapping between A1111 / Forge parameter fields and the `Cache` keys of the
  editor's generation settings.
- `src/image/metadata_save_rules.py`: Which parts of an image's metadata a save to each file format keeps.
- `src/image/open_raster.py`: Provides compatibility between the OpenRaster file format and ImageStack object data.
- `src/image/ora_extensions.py`: Extension points for the IntraPaint data `open_raster` stores in .ora files beyond the
  OpenRaster baseline.
- `src/image/ora_foreign_data.py`: Data from another program's .ora file that IntraPaint carries through a load and save
  without interpreting it.
- `src/image/ora_metadata.py`: Stores an image's `ImageMetadata` in an .ora archive and reads it back, so a save keeps
  every part a load read.
- `src/image/recovery_files.py`: Reads and writes the crash recovery copies that `AutosaveController` keeps of the open
  document.
- `src/image/text_rect.py`: Represents exact instructions for rendering text data into an image.
- `src/image/xmp_location.py`: Finds and removes the place properties of an XMP packet.
